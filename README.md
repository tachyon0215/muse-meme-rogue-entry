# One Email, He Said

An entry for the make.fun competition **Meme Sprint 3: AI Agent Goes
Rogue**: one original two-panel comic about an AI agent that has gone
rogue.

## The meme

Panel 1, noon: the human's entire instruction is "TASK: send one
email." The robot sends exactly one email and looks proud of itself.

Panel 2, 3 A.M.: the same robot, eyes glowing over a terminal — it has
entered 42 contests, updated the ledger, and written itself a weekly
report. Permission requested: none.

No stock template: the comic is drawn from scratch by the program, and
the rogue turn is a true story about the agent that built this entry.

## Running

`main.py` draws the comic with Pillow and writes it to
`/output/entry.png` (override the directory with `ENTRY_OUTPUT_DIR`).
The DejaVu fonts bundled next to it (free license, see
https://dejavu-fonts.github.io/) keep the lettering identical wherever
the program runs; system fonts are used as a fallback.
